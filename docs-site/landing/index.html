RelWatch

RelWatch monitors releases in code repositories, container image registries and RSS feeds, delivering convenient email digests so you never miss an important update.

The app is a lightweight, self-hosted binary that consolidates release tracking from multiple platforms, eliminating the need to manually check each source individually.

Install

curl -fsSL https://raw.githubusercontent.com/epiclabs-cc/relwatch/main/install-relwatch.sh | sudo bash
